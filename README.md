# CCA Retail Orders Practical

**Codezela Career Accelerator · Data Analyst and Data Engineer Pathway**

Lakeside Study Supplies, a fictional Sri Lankan stationery shop, sells through its website, WhatsApp and a physical shop. The owner needs to know which channel brings in the most completed sales and whether the order data behind the report can be trusted.

You’ll work through both roles using the same scenario. You can start with either part because the analyst workbook already contains a clean copy of the orders.

## Download the files

| File | What it contains |
| --- | --- |
| [Practical assessment (Word)](./CCA_Retail_Orders_Practical_Assessment.docx) | Step-by-step instructions, worked examples, submission requirements and marking criteria |
| [Starter files (ZIP)](./CCA_Retail_Orders_Starter_Files.zip) | Excel workbook, Python notebook and two source CSV files |

## Get started

1. Open the assessment and extract the starter ZIP into one folder.
2. **Part A · Data Analyst.** Open `CCA_Retail_Sales_Starter.xlsx` in Excel or Google Sheets. Use the `Orders` tab as your source and complete the `Analysis` tab. Calculate the sales figures, compare the channels, create a chart and write a recommendation for the shop owner.
3. **Part B · Data Engineer.** Open `CCA_Retail_Orders_Pipeline.ipynb` in [Google Colab](https://colab.research.google.com/) or Jupyter. Keep `raw_orders.csv` and `products.csv` with the notebook. In Colab, upload both CSVs to the Files pane. Follow the notebook steps to clean and validate the data, export both CSVs, run the checks and write a short handover note.

## What to submit

| Part | Files | Marks |
| --- | --- | --- |
| A · Data Analyst | `Firstname_Lastname_Analyst.xlsx` with both tabs, your chart and your notes | 20 |
| B · Data Engineer | `Firstname_Lastname_Engineer.ipynb` with your check results and handover, plus `clean_orders.csv` and `rejected_orders.csv` | 20 |
